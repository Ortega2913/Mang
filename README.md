# Mang

- **`/`** — Remotion motion graphics project (overlay rendering for video).
- **`/web`** — [Lumora AI](./web/README.md), a free AI image & video
  generator website (Next.js), deployable to Vercel/Netlify for free.

See `web/README.md` for details on running and deploying the AI generator
website.
